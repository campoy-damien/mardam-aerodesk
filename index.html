MARDAM AeroDesk Pro
Gestion du personnel aéronautique — by Damien Campoy
Application tout-en-un centralisant plannings, formations, chantiers, certifications et recyclage d'aéronefs. Données sauvegardées localement (localStorage) et synchronisables via Google Drive.

Programme Activité
Charge / capacité & Gantt annuel
▼
Tableau de bord stratégique — charge vs capacité sur toute l'année.
• DISPO — techniciens réellement disponibles (capacité, absences déduites)
• BESOIN — 🔧 Chantiers + ✈️ Stockage + ♻️ Recyclage cumulés

🧮
Méthodes de calcul du personnel
Comment l'app calcule DISPO, BESOIN et ÉCART
▼
1 · La CAPACITÉ (DISPO) — combien de personnes peuvent travailler
L'app part de l'effectif réellement qualifié et productif, c'est-à-dire les personnes dont la catégorie est Technicien ou Intérimaire. Les responsables, chefs d'équipe, experts, fonctions support et apprentis/alternants ne sont pas comptés dans la capacité de production — les apprentis ne sont pas (encore) qualifiés et n'apportent pas de main d'œuvre productive sur les chantiers.

Pour chaque semaine, l'app regarde le planning de chacun (lundi → vendredi, en demi-journées AM/PM) et calcule un taux de présence :
• Une demi-journée en Travail = présent  ·  une demi-journée en Congé / Maladie / Formation / Absence / Déplacement / Férié = absent
• Une personne présente toute la semaine compte pour 1,0  ·  absente la moitié = 0,5
DISPO de la semaine = somme des taux de présence de tous les techniciens et intérimaires (apprentis exclus).
Ex : 60 techniciens, dont 4 en congé toute la semaine et 2 à mi-temps → 60 − 4 − 1 = 55 dispo.
2 · Le BESOIN — combien de personnes sont nécessaires
Le besoin est la somme, semaine par semaine, de trois sources :
• 🔧 Chantiers — chaque chantier a un besoin théorique en techniciens (champ Ressources de la fiche chantier). Ce besoin est compté pour toutes les semaines où le chantier est actif (entre sa date de début et de fin).
• ✈️ Stockage — calculé à partir des heures (man-hours) saisies par semaine, converties en techniciens : 1 technicien ≈ 35 h/semaine. Soit besoin = heures ÷ 35, arrondi au supérieur.
• ♻️ Recyclage — selon les avions en cours de démantèlement et leur cadence.
BESOIN de la semaine = Σ besoins chantiers actifs + besoin stockage + besoin recyclage.
3 · Les AJUSTEMENTS manuels (avance / retard)
Le besoin théorique d'un chantier s'applique uniformément à toutes ses semaines. Mais en réalité un chantier peut prendre de l'avance ou du retard. Le tableau d'ajustement (bas du Programme Activité) permet de corriger le besoin d'un chantier pour une semaine précise :
• Case jaune = valeur ajustée manuellement (remplace le théorique pour cette semaine uniquement)
• Case rouge = prolongation au-delà de la date de fin théorique (chantier en retard)
• Remettre la valeur théorique efface l'ajustement
💡 Le besoin théorique de la fiche chantier n'est jamais modifié : les ajustements sont stockés séparément et n'affectent que les semaines concernées.
4 · L'ÉCART — le verdict
ÉCART = DISPO − BESOIN
• Écart positif (vert) — surplus de techniciens disponibles cette semaine (ex : +17 = 17 personnes en plus du besoin)
• Écart négatif (rouge) — manque : il faut mobiliser des intérimaires ou décaler de la charge
• Le détail par semaine (clic sur "détail") montre la répartition chantier par chantier, avec le théorique et l'ajusté quand ils diffèrent.
5 · Catégories de personnel
• Comptés dans la capacité (production) : Technicien, Intérimaire
• Non comptés : Apprenti/Alternant (pas encore qualifié, n'apporte pas de main d'œuvre productive), Responsable, Chef d'équipe, Expert et autres fonctions support
Les responsables, chefs et apprentis apparaissent dans le planning et les Gantts de présence (Chantiers, Recyclage, Stockage, Part 21) mais pas dans le calcul de la capacité de production.
✅ En résumé : la capacité vient du planning réel, le besoin vient des chantiers + modules (ajustable à la semaine), et l'écart te dit s'il faut renforcer ou si tu as de la marge.

Assistant interne
100% interne, gratuit, hors-ligne
▼
L'assistant fonctionne entièrement en local (aucun service payant, aucune donnée envoyée à l'extérieur). Il calcule ses réponses à partir de tes données. Tape ta question dans le langage courant :
• Formations qui expirent — "Quelles formations expirent bientôt ?", "Qui n'a pas le CACES nacelle à jour ?"
• Présence / absence — "Qui est en congé semaine 30 ?", "Quels chefs sont présents semaine 30 ?"
• Personnel disponible — "Combien de techniciens dispo cette semaine ?"
• Chantiers — "État des chantiers", "Quels chantiers manquent de monde ?"
• Recherche — "Infos sur Baou"
• Simulation de faisabilité — "5 techniciens en semaine 32 et 33 ?" → verdict OUI/NON/PARTIEL selon la capacité résiduelle réelle
• Actions sur le planning — "Mets Baou et Castanon sur le chantier 5598 semaine 33", "Plannifie Gohe en formation CDCCL le 13 juillet", "Mets Dupont en congé du 2 au 6 juin"
💡 Toute action sur le planning passe par un aperçu avec gestion des conflits (garder/écraser) et un bouton ↩ Annuler. Rien n'est modifié sans ta confirmation. Les formations sont classées internes 📖 sauf les CACES des intérimaires 📚.

Sauvegarde & Synchronisation
Sécuriser et partager tes données
▼
• Automatique en local — chaque modification est sauvegardée immédiatement dans le navigateur
• Synchro Google Drive bidirectionnelle ☁️ — tes appareils (Windows, iPad, iPhone) se synchronisent tout seuls. Quand tu reviens sur l'app, elle récupère automatiquement la dernière version si un autre appareil a fait des modifications plus récentes (petit message "✓ Données mises à jour")
• Export / Import JSON 💾 — sauvegarde ou recharge une copie complète des données
💡 La synchro se déclenche au retour sur l'app et toutes les 2-3 min. Elle ne charge la version distante que si elle est plus récente que la tienne — ta version récente ne se fait jamais écraser.
⚠️ Vider le cache du navigateur supprime les données locales. Garde Google Drive activé pour ne rien perdre.
📥
Import suivi RH
Mise à jour des formations depuis les fichiers RH
▼
Dans l'onglet Formations, le bouton 📥 Import suivi RH (2 fichiers) permet de charger les deux fichiers Excel envoyés chaque mois par le service RH (Qualité + SSE).
• Site filtré — seules les lignes du site LFBF sont prises en compte
• Correspondance — par trigramme, avec vérification du nom (anomalies signalées)
• Mapping automatique — les intitulés RH sont traduits vers les formations de l'app (EWIS, CDCCL, CACES…), les colonnes Forklift sont mutualisées
• Aperçu avant validation — la liste des ajouts/mises à jour s'affiche, rien n'est appliqué tant que tu n'as pas confirmé
💡 L'import met à jour les dates d'expiration existantes ET ajoute les formations manquantes. Nécessite une connexion internet (lecture des fichiers Excel).
📊
Export Excel coloré
Planning hebdo en Excel avec couleurs
▼
Le bouton 📊 Export Excel du planning hebdo génère un vrai fichier .xlsx avec les couleurs identiques à l'app.
• Une colonne par jour — le nom du chantier/activité s'affiche dans chaque cellule, coloré selon le chantier
• Matin / après-midi — si la journée est coupée, la cellule affiche "Chantier A / Chantier B"
• Noms colorés par catégorie + deux légendes (catégories de personnel et activités)
• Volets figés — la colonne des noms et la ligne des jours restent visibles au défilement
💡 Nécessite une connexion internet au moment de l'export (chargement de la librairie Excel).

☁️ Sync Google Drive
☁️ Comment ça marche ?

Tu crées un mini-script gratuit sur Google Apps Script (script.google.com).
Il stocke tes données dans un fichier de ton Google Drive personnel.
L'app se synchronise automatiquement — iPhone · iPad · PC Windows.

Configuration — 3 étapes
1
Ouvrir Google Apps Script
Connecté à ton compte Google, clique sur le lien ci-dessous. Crée un Nouveau projet.
2
Coller le code dans l'éditeur
Supprime tout le code existant dans l'éditeur, puis colle ce code :
const FOLDER_NAME = 'AeroStaff';
const FILE_NAME   = 'AeroStaff_Data.json';

function doPost(e) {
  try {
    const data = e.postData.contents;
    saveToFile(data);
    return ContentService
      .createTextOutput(JSON.stringify({ok:true}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService
      .createTextOutput(JSON.stringify({ok:false,error:err.message}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  try {
    const files = DriveApp.getFilesByName(FILE_NAME);
    if (files.hasNext()) {
      const content = files.next().getBlob().getDataAsString();
      return ContentService
        .createTextOutput(content)
        .setMimeType(ContentService.MimeType.JSON);
    }
    return ContentService
      .createTextOutput('{}')
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService
      .createTextOutput('{}')
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function saveToFile(data) {
  const files = DriveApp.getFilesByName(FILE_NAME);
  if (files.hasNext()) {
    files.next().setContent(data);
  } else {
    DriveApp.createFile(FILE_NAME, data, MimeType.PLAIN_TEXT);
  }
}
