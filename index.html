MARDAM AeroDesk Pro
Gestion du personnel aéronautique — by Damien Campoy
Application tout-en-un centralisant plannings, formations, chantiers, certifications et recyclage d'aéronefs. Données sauvegardées localement (localStorage) et synchronisables via Google Drive.
🏠
Tableau de bord
Vue synthétique en temps réel
▼
Point d'entrée de l'app. Affiche en un coup d'œil :
• Compteurs clés — effectif, techniciens actifs, intérimaires, apprentis
• Alertes formations — habilitations expirant dans les 30 jours
• Ratio charge/capacité — aperçu de la semaine en cours
• Chantiers en cours — statut rapide
💡 Se met à jour automatiquement à chaque ouverture.

Master Planning
Vue annuelle de l'équipe
▼
Vue macro sur 12 mois — une ligne par personne, une colonne par jour (demi-journées AM/PM).
• Code couleur — chaque chantier a sa couleur ; congés, formations, absences, fériés et week-ends ont la leur
• Colonne des noms en noir — figée à gauche au défilement, regroupée par catégorie de personnel
• Clic sur une case — saisir/modifier l'activité (mêmes données que le Planning Hebdo)
• Filtres — par personne et par année
• 📊 Export Excel coloré — fichier .xlsx avec les couleurs des chantiers, personnel regroupé par catégorie, nom de chantier + MSN dans chaque case, volets figés et légendes
• 📄 Export PDF — rendu coloré regroupé par catégorie, nom de chantier complet dans les cases + légende, idéal à envoyer aux collaborateurs
💡 Après avoir saisi une case, le planning reste à la position où tu étais — plus besoin de rescroller. Mêmes données que le Planning Hebdo.

Planning Hebdomadaire
Gestion jour par jour AM/PM
▼
Cœur opérationnel — affectations à la demi-journée pour chaque personne.
• Grille AM/PM — chaque case = une demi-journée
• Clic sur une case — Travail, Congé, Formation, Maladie, Déplacement…
• Affectation chantier — Travail → choisir le chantier associé (y compris Stockage, Part 21, ou un avion en recyclage)
• 2 chantiers par demi-journée — une demi-journée peut porter un 2ᵉ chantier optionnel (jusqu'à 4 chantiers/jour). Les 3,5 h sont alors divisées à parts égales (1,75 h chacun). La case s'affiche en 2 bandes de couleur avec le MSN de chaque avion.
• Copier semaine — duplique le planning vers une autre semaine
• 📊 Export Excel coloré & 📄 PDF — rendu identique à l'app, avec couleurs, MSN des chantiers et légendes (cases scindées pour les demi-journées à 2 chantiers)
• Navigation — ← Préc. / Aujourd'hui / Suiv. →
✅ Les absences saisies ici sont déduites automatiquement de la capacité dans Programme Activité. Après chaque saisie, la vue reste à la même position pour enchaîner les cases sans rescroller.

Chantiers
Gestion des travaux et affectations
▼
• + Chantier — client, avion, MSN, dates, volume Man Hours, techniciens requis. Le nom est composé automatiquement « Client — Avion — MSN ».
• Statuts — En cours / Futur / Prévu / Terminé — impactent la charge
• Suivi d'avancement (carte sur le dashboard) — avancement réel = MH consommées (techniciens/intérimaires affectés dans le planning × 7 h/jour) ÷ MH total, comparé à l'avancement théorique (jours ouvrés écoulés) → statut ✅ en avance / 🟡 dans les temps / 🚨 en retard
• Volume MH — saisissable directement sur la carte du dashboard (ou dans la fiche)
• 🔧 Heures ajoutées — sur chaque chantier en cours, ajoutez des heures de rectification/défaut (motif + heures, autant que nécessaire). L'app affiche alors les deux avancements (périmètre initial vs révisé) et calcule l'impact : combien de techniciens ajouter pour tenir la date, ou la nouvelle date de livraison à effectif constant.
💡 "En cours" et "Futur" alimentent le tableau de charge dans Programme Activité. Seuls les techniciens et intérimaires comptent dans les Man Hours consommées (pas les apprentis ni l'encadrement).

Méthodes de calcul du personnel
Comment l'app calcule DISPO, BESOIN et ÉCART
▼
1 · La CAPACITÉ (DISPO) — combien de personnes peuvent travailler
L'app part de l'effectif réellement qualifié et productif, c'est-à-dire les personnes dont la catégorie est Technicien ou Intérimaire. Les responsables, chefs d'équipe, experts, fonctions support et apprentis/alternants ne sont pas comptés dans la capacité de production — les apprentis ne sont pas (encore) qualifiés et n'apportent pas de main d'œuvre productive sur les chantiers.

Pour chaque semaine, l'app regarde le planning de chacun (lundi → vendredi, en demi-journées AM/PM) et calcule un taux de présence :
• Une demi-journée en Travail = présent  ·  une demi-journée en Congé / Maladie / Formation / Absence / Déplacement / Férié = absent
• Une personne présente toute la semaine compte pour 1,0  ·  absente la moitié = 0,5
DISPO de la semaine = somme des taux de présence de tous les techniciens et intérimaires (apprentis exclus).
Ex : 60 techniciens, dont 4 en congé toute la semaine et 2 à mi-temps → 60 − 4 − 1 = 55 dispo.
2 · Le BESOIN — combien de personnes sont nécessaires
Le besoin est la somme, semaine par semaine, de quatre sources :
• 🔧 Chantiers — chaque chantier a un besoin théorique en techniciens (champ Ressources de la fiche chantier). Ce besoin est compté pour toutes les semaines où le chantier est actif (entre sa date de début et de fin).
• ✈️ Stockage — calculé à partir des heures (man-hours) saisies par semaine, converties en techniciens : 1 technicien ≈ 35 h/semaine. Soit besoin = heures ÷ 35, arrondi au supérieur.
• ✈️ Airbus Part 21 — techniciens P21 + Inspection Qualité saisis par semaine dans l'onglet dédié.
• ♻️ Recyclage — pour chaque avion en cours/à venir, dans cet ordre de priorité : 1. les techniciens « recyclage » réellement affectés à l'avion dans le planning ; 2. sinon le nombre fixe saisi sur la fiche avion ; 3. sinon le calcul par pièces (pièces de la semaine ÷ (pièces/heure × 5 jours), arrondi au supérieur).
BESOIN de la semaine = Σ besoins chantiers actifs + besoin stockage + besoin Part 21 + besoin recyclage.
Le clic sur « ⓘ détail » d'une semaine montre la contribution de chaque source, avec une ligne par avion en recyclage.
3 · Les AJUSTEMENTS manuels (avance / retard)
Le besoin théorique d'un chantier s'applique uniformément à toutes ses semaines. Mais en réalité un chantier peut démarrer en avance ou prendre du retard. Le tableau d'ajustement (bas du Programme Activité) couvre toute l'année (janvier → décembre, scrollable) et dispose de son propre sélecteur d'année (jusqu'à 2060, indépendant du Gantt). Il permet de corriger le besoin d'un chantier pour une semaine précise :
• Case jaune = valeur ajustée manuellement (remplace le théorique pour cette semaine uniquement)
• Bouton + sur une semaine hors période = ajouter un besoin là où le chantier n'est pas censé tourner : ⏪ démarrage anticipé (avant la date de début) ou ⏩ prolongation/retard (après la date de fin)
• Vider une case ajoutée la retire ; remettre la valeur théorique efface l'ajustement
💡 Le besoin théorique de la fiche chantier n'est jamais modifié : les ajustements sont stockés séparément et n'affectent que les semaines concernées.
4 · L'ÉCART — le verdict
ÉCART = DISPO − BESOIN
• Écart positif (vert) — surplus de techniciens disponibles cette semaine (ex : +17 = 17 personnes en plus du besoin)
• Écart négatif (rouge) — manque : il faut mobiliser des intérimaires ou décaler de la charge
• Le détail par semaine (clic sur "détail") montre la répartition chantier par chantier, avec le théorique et l'ajusté quand ils diffèrent.
5 · Catégories de personnel
• Comptés dans la capacité (production) : Technicien, Intérimaire
• Non comptés : Apprenti/Alternant (pas encore qualifié, n'apporte pas de main d'œuvre productive), Responsable, Chef d'équipe, Expert et autres fonctions support
Les responsables, chefs et apprentis apparaissent dans le planning et les Gantts de présence (Chantiers, Recyclage, Stockage, Part 21) mais pas dans le calcul de la capacité de production.
6 · Man Hours & avancement des chantiers
• Heures consommées — chaque demi-journée où un technicien ou intérimaire est affecté à un chantier compte pour 3,5 h (base 7 h/jour). Seules les affectations jusqu'à aujourd'hui inclus sont comptées ; les week-ends/fériés comptent s'ils sont explicitement affectés.
• 2 chantiers sur une même demi-journée — les 3,5 h sont divisées à parts égales : 1,75 h pour chacun des deux chantiers.
• Avancement réel = heures consommées ÷ volume Man Hours total (initial + heures ajoutées) × 100.
• Avancement théorique = jours ouvrés écoulés ÷ jours ouvrés totaux × 100. L'écart entre réel et théorique donne le statut ✅/🟡/🚨.
• Heures ajoutées — pour tenir la date : techniciens nécessaires = heures restantes ÷ (jours ouvrés restants × 7). Nouvelle date à effectif constant = heures restantes ÷ (nb techniciens prévus × 7), reportée en jours ouvrés.
7 · Base de calcul du Tableau de bord KPI
Les KPI sont calculés sur la semaine en cours (et les 8 semaines à venir pour le sous-effectif) :
• Taux de disponibilité = DISPO ÷ effectif productif  ·  Absentéisme = demi-journées congé+maladie ÷ total demi-journées productives
• Avancement moyen chantiers = moyenne pondérée par les Man Hours  ·  Dérive de périmètre = heures ajoutées ÷ heures initiales
• Conformité habilitations = personnel sans aucune qualification expirée ÷ effectif actif  ·  Compétences à risque = qualifications détenues (valides) par ≤ 1 personne
• Code couleur 🟢 bon / 🟡 vigilance / 🔴 alerte selon des seuils adaptés à chaque indicateur.
✅ En résumé : la capacité vient du planning réel, le besoin vient des chantiers + modules (ajustable à la semaine), et l'écart te dit s'il faut renforcer ou si tu as de la marge.

Assistant interne
100% interne, gratuit, hors-ligne
▼
L'assistant fonctionne entièrement en local (aucun service payant, aucune donnée envoyée à l'extérieur). Il calcule ses réponses à partir de tes données. Tape ta question dans le langage courant :
• Échéances — "Quelles formations expirent dans les 6 mois ?", "Autorisations à renouveler cette année" (l'horizon est compris : 3 mois, 6 mois, fin d'année…)
• Présence / absence — "Qui est en congé cette semaine ?", "Quels chefs sont présents la semaine prochaine ?"
• Disponibilité & charge — "Combien de techniciens dispo cette semaine ?", "Écart capacité/besoin", "Compare cette semaine et la semaine prochaine"
• Recherche croisée — "Qui a le CACES nacelle ET est dispo cette semaine ?", "Quels techniciens ont l'EWIS valide ?" (combine plusieurs qualifications + présence + catégorie)
• Chantiers / recyclage / stockage — "État des chantiers", "Quels chantiers manquent de monde ?"
• Activité par mois — "Chantiers actifs au mois d'août", "Avions en recyclage en septembre", ou le point global "Que se passe-t-il ce mois-ci ?" (combine chantiers + recyclage actifs sur le mois ; l'année est prise en compte si précisée)
• Simulation & actions — "5 techniciens du 01/09 au 30/09 ?", "Mets Baou sur le chantier 5598 la semaine prochaine", "Mets Dupont en congé du 2 au 6 juin"
• Suggestions par thème — des exemples classés (Charge, Présence, Activité, Formations, Recherche croisée, Effectif, Simulation) au-dessus de la zone de saisie
• Réponses cliquables — les noms ouvrent la fiche de la personne, et un bouton ouvre directement le planning de la semaine concernée
• Tolérance aux fautes & dictée vocale — comprend les fautes de frappe ; la dictée laisse le texte modifiable avant envoi
💡 Toute action sur le planning passe par un aperçu avec gestion des conflits (garder/écraser) et un bouton ↩ Annuler. Rien n'est modifié sans ta confirmation. Une question (« qui… », « combien… ») n'est jamais exécutée comme un ordre.

Sauvegarde & Synchronisation
Sécuriser et partager tes données
▼
• Automatique en local — chaque modification est sauvegardée immédiatement dans le navigateur

☁️ Sync Google Drive
☁️ Comment ça marche ?

Tu crées un mini-script gratuit sur Google Apps Script (script.google.com).
Il stocke tes données dans un fichier de ton Google Drive personnel.
L'app se synchronise automatiquement — iPhone · iPad · PC Windows.

Configuration — 3 étapes
1
Ouvrir Google Apps Script
Connecté à ton compte Google, clique sur le lien ci-dessous. Crée un Nouveau projet.
2
Coller le code dans l'éditeur
Supprime tout le code existant dans l'éditeur, puis colle ce code :
const FOLDER_NAME = 'AeroStaff';
const FILE_NAME   = 'AeroStaff_Data.json';

function doPost(e) {
  try {
    const data = e.postData.contents;
    saveToFile(data);
    return ContentService
      .createTextOutput(JSON.stringify({ok:true}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService
      .createTextOutput(JSON.stringify({ok:false,error:err.message}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  try {
    const files = DriveApp.getFilesByName(FILE_NAME);
    if (files.hasNext()) {
      const content = files.next().getBlob().getDataAsString();
      return ContentService
        .createTextOutput(content)
        .setMimeType(ContentService.MimeType.JSON);
    }
    return ContentService
      .createTextOutput('{}')
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService
      .createTextOutput('{}')
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function saveToFile(data) {
  const files = DriveApp.getFilesByName(FILE_NAME);
  if (files.hasNext()) {
    files.next().setContent(data);
  } else {
    DriveApp.createFile(FILE_NAME, data, MimeType.PLAIN_TEXT);
  }
}
3
Déployer et coller l'URL
Dans Google Apps Script : Déployer → Nouveau déploiement
Type : Application Web
Exécuter en tant que : Moi
Qui a accès : Tout le monde
→ Clique Déployer, autorise les permissions, copie l'URL.
